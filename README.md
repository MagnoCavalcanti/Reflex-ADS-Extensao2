# Reflex ADS

Front-end do MVP Reflex ADS, desenvolvido com React, TypeScript, Vite e Tailwind CSS.

## Configuração

Crie um `.env.local` na raiz do projeto usando o arquivo `.env.local.example` como base:

```env
VITE_API_URL=https://reflex-server-eoxc.onrender.com
```

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```
